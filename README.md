🚍 TransitPulse AI

TransitPulse AI is a smart and user-friendly platform designed to provide information about government bus services in different states and cities.

🌟 Features

- State-wise government bus information
- City selection
- Bus route and timing information
- Simple and user-friendly interface
- Responsive design for mobile and desktop
- AI-powered transit information

🎯 Purpose

The main purpose of TransitPulse AI is to make government bus information easier to access and understand through a simple digital platform.

🛠️ Technologies Used

- HTML
- CSS
- TypeScript
- Vite
- Google Gemini AI Studio
- Vercel

📂 Project Structure

- "src/" — Application source code
- "index.html" — Main HTML file
- "package.json" — Project dependencies and scripts
- "vite.config" — Vite configuration

🔮 Future Scope

- Add more cities and routes
- Real-time bus tracking
